# Сайт-приглашение на свадьбу Сони и Серёжи

Статический сайт без сборщиков и npm. Работает «из коробки» — просто открой `index.html` в браузере.

---

## Структура файлов

```
wedding-invite/
├── index.html         — вся разметка страницы
├── styles.css         — стили и анимации
├── app.js             — персонализация, обратный отсчёт, отправка анкеты
├── config.json        — общие данные (дата, адрес, телефоны, URL Google-скрипта)
├── guests.json        — список гостей: код → приветствие + тип
├── assets/
│   ├── couple/        — фото молодожёнов
│   ├── location/      — фото фермы
│   └── dresscode/     — фото для карусели дресс-кода
├── tools/
│   └── new-code.html  — генератор кодов для новых гостей
└── docs/
    ├── README.md      — эта инструкция
    ├── google-sheets.md — настройка Google Таблицы
    ├── guests.md      — управление гостями
    └── domain.md      — привязка своего домена
```

---

## Быстрый старт: что нужно сделать

1. **Настроить Google Таблицу** — см. `docs/google-sheets.md`  
   Получишь URL скрипта и вставишь его в `config.json` → `formEndpoint`.

2. **Добавить гостей** — см. `docs/guests.md`  
   Используй генератор `tools/new-code.html` для создания кодов.

3. **Опубликовать на GitHub Pages** — см. `docs/domain.md`

---

## Как редактировать текст

### Общие данные (дата, адрес, телефоны)

Открой `config.json`. Все ключевые данные собраны там.

### Текст на странице

Открой `index.html` и найди нужный текст (Cmd+F / Ctrl+F — поиск). Измени прямо там.

Удобно редактировать на GitHub: нажми на файл → иконка карандаша → правь → **Commit changes**.

---

## Как поменять фото

1. Подготовь новый файл (JPG/WEBP, желательно меньше 500 КБ).
2. Положи его в нужную папку `assets/...`.
3. Обнови путь в `index.html`, если имя файла изменилось.
4. Если редактируешь через GitHub: **Add file → Upload files** → загрузи файл в нужную папку.

---

## Как изменить анкету

Поля анкеты находятся в `index.html` внутри `<form id="rsvp-form">`.

- Скопируй блок `<div class="form-group">` с нужным полем как шаблон.
- Измени `name="..."` — это имя колонки в Google Таблице.
- Если поле должно показываться только для определённого типа гостя, добавь атрибут `data-show-for="family"` или `data-show-for="friend"`.
- Добавь новый `name` в `appendRow` Google Apps Script и задеплой заново.

---

## Как создать персональную ссылку

1. Открой `tools/new-code.html` в браузере.
2. Введи приветствие и тип гостя.
3. Нажми «Сгенерировать».
4. Скопируй JSON-фрагмент в `guests.json`.
5. Дай гостю ссылку: `https://твой-сайт/?g=код`.

---

## Как посмотреть ответы

Открой Google Таблицу «Свадьба — анкета». Каждый ответ — новая строка.

Формулы для быстрого подсчёта:
- Количество «да»: `=COUNTIF(B:B,"да")`
- Количество «нет»: `=COUNTIF(B:B,"нет")`
