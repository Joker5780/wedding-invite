# Управление гостями и персональными ссылками

## Структура guests.json

Файл `guests.json` содержит список всех гостей. Каждый гость — это объект по ключу (6-значный код):

```json
{
  "default":  { "greeting": "Дорогие друзья и родные!", "type": "default" },
  "a7f3k2":   { "greeting": "Дорогая Аня!",             "type": "friend", "note": "Аня Иванова" },
  "x9m4qp":   { "greeting": "Дорогие мама и папа!",     "type": "family", "note": "родители Сони" }
}
```

**Поля:**
- `greeting` — текст приветствия на сайте (только вы его задаёте, в URL имя не светится)
- `type` — тип гостя: `default`, `friend`, `family`
- `note` — ваша заметка (не видна гостям, только для удобства)

## Типы гостей и условные блоки

| Тип | Что появляется дополнительно |
|-----|------------------------------|
| `default` | Только базовые поля анкеты |
| `friend` | + поле «Что бы вы хотели нам сказать?» |
| `family` | + вопрос «Нужно ли вам жильё?» |

## Как добавить нового гостя

### Способ 1: Генератор (рекомендуется)

1. Открой `tools/new-code.html` в браузере (двойной клик на файл).
2. Введи приветствие, тип и заметку.
3. Нажми «Сгенерировать».
4. Скопируй JSON-фрагмент и вставь в `guests.json`.

### Способ 2: Вручную

Добавь строку в `guests.json`, например:

```json
"k3p7vn": { "greeting": "Дорогая Катя!", "type": "friend", "note": "Катя с работы" }
```

Код — любые 6 символов (буквы и цифры без 0, O, 1, I во избежание путаницы).

## Персональная ссылка

Ссылка для гостя:
```
https://ваш-домен/?g=k3p7vn
```

Если сайт на GitHub Pages:
```
https://ник.github.io/wedding-invite/?g=k3p7vn
```

## Рекомендуемый учёт

Удобно держать отдельный лист «Гости» в Google Таблице:

| Код | Кому | Ссылка | Отправлено | Ответ |
|-----|------|--------|------------|-------|
| k3p7vn | Катя с работы | https://…/?g=k3p7vn | WhatsApp 15 июля | да |

Из колонки «Ответ» видно — кто из invited уже заполнил анкету.
