# Привязка своего домена

## Шаг 1. Купить домен

Рекомендуемые сервисы:
- [reg.ru](https://reg.ru) — популярный российский регистратор (~200–700 ₽/год для `.ru`)
- [timeweb.ru](https://timeweb.ru)
- [nic.ru](https://nic.ru)

Выбери домен, например `sonya-and-seryozha.ru`.

---

## Шаг 2. Опубликовать сайт на GitHub Pages

1. Создай аккаунт на [github.com](https://github.com) (если нет).
2. Создай новый репозиторий: **New repository** → название `wedding-invite` (или любое другое).
3. Загрузи файлы:
   - Через сайт: **Add file → Upload files** — перетащи всё содержимое папки `wedding-invite/`.
   - Или через командную строку:
     ```bash
     git init
     git add .
     git commit -m "Initial"
     git remote add origin https://github.com/твой-ник/wedding-invite.git
     git push -u origin main
     ```
4. В репозитории: **Settings → Pages → Source: Deploy from branch → main → / (root) → Save**.
5. Через 30–60 секунд сайт доступен по адресу: `https://твой-ник.github.io/wedding-invite/`.

---

## Шаг 3. Создать файл CNAME в репозитории

Создай в корне репозитория файл `CNAME` (без расширения) с содержимым:
```
sonya-and-seryozha.ru
```

Закоммить и запушь.

---

## Шаг 4. Настроить DNS у регистратора

В панели управления доменом добавь следующие записи:

**A-записи** (тип A):
| Хост | Адрес |
|------|-------|
| @ | 185.199.108.153 |
| @ | 185.199.109.153 |
| @ | 185.199.110.153 |
| @ | 185.199.111.153 |

**CNAME-запись**:
| Хост | Значение |
|------|----------|
| www | твой-ник.github.io |

DNS обновляется до 24 часов (обычно 15–60 минут).

---

## Шаг 5. Включить HTTPS

1. В GitHub репозитории: **Settings → Pages**.
2. Убедись, что в поле **Custom domain** стоит твой домен.
3. Подожди, пока появится галочка «✅ Your site is published at…» — тогда поставь галочку **Enforce HTTPS**.

После этого сайт доступен по `https://sonya-and-seryozha.ru` — и все ссылки гостям можно раздавать уже в таком виде.

---

## Обновление сайта после публикации

1. Отредактируй нужный файл.
2. Закоммить и запушь:
   ```bash
   git add .
   git commit -m "Обновление"
   git push
   ```
3. GitHub Pages автоматически обновит сайт через 30–60 секунд.

Или прямо на GitHub.com: нажми на файл → иконка карандаша (Edit) → внеси правки → **Commit changes**.
